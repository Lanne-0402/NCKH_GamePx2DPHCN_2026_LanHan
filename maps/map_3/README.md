# Map 3 - Đẩy lùi tường

Map 3 triển khai bài tập khép ngang khớp vai:

- Cánh tay gấp 90°, cẳng tay nâng ngang vai.
- Dạng hai cánh tay sang hai bên nhiều nhất có thể.
- Giữ đúng tư thế 5 giây/lần.
- **2 phase × 5 lần** (tổng 10 lần), **nghỉ 30 giây** giữa phase.
- Tường gai luân phiên theo 4 hướng.
